Help

Technical Support

Get help with 7-Zip — from the community forum to direct bug reporting.

✅ Before Requesting Support
1 Check that you are using the latest version of 7-Zip.
2 Try the latest development/beta version — your issue may already be fixed.
3 On 64-bit Windows, make sure you use the 7-Zip x64 installer.
4 Check the 7-Zip help system installed with the application.
5 Read the FAQ page for answers to common questions.
6 Search the 7-Zip forum for similar reports.
