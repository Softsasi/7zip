About LZMA SDK

The LZMA SDK provides the documentation, samples, header files, libraries, and tools you need to develop applications that use LZMA compression. LZMA and LZMA2 are the default compression methods of the 7z format.

LZMA provides a high compression ratio and fast decompression, making it ideal for embedded applications such as ROM/firmware compression.

What's Included

C++ Source Code
LZMA Encoder, Decoder, and .7z compression/decompression (reduced version)
ANSI-C Code
Compatible LZMA / LZMA2 / XZ compression and 7z decompression with examples
C# Source Code
LZMA compression and decompression for .NET applications
Java Source Code
LZMA compression and decompression for Java applications
lzma.exe
Command-line tool for .lzma compression and decompression
SFX Modules
Create self-extracting packages and installers from 7z archives

LZMA Performance

MetricPerformance
Compression speed2–8 MB/s on 4 GHz CPU (2 threads)
Decompression (modern CPU)30–100 MB/s on 4 GHz CPU (Intel, AMD, ARM)
Decompression (RISC CPU)5–15 MB/s on 1 GHz RISC (ARM, MIPS, PowerPC)
Decompression memory8–32 KB + DictionarySize
Decompression code size2–8 KB (depending on speed optimizations)

The LZMA decoder uses only CPU integer instructions and can be implemented for any modern 32-bit CPU.

💡 Note on the Name

LZMA originally stood for Lempel–Ziv–Markov chain–Arithmetic coding. Early versions used arithmetic coding, but the final version replaced it with range coding — delivering better performance.
