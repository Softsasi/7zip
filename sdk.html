LZMA SDK

LZMA SDK provides the documentation, samples, header files, libraries, and tools you need to develop applications that use LZMA and LZMA2 compression.

Download LZMA SDK 24.08 (.7z)

License

LZMA SDK is placed in the public domain. Anyone is free to copy, modify, publish, use, compile, sell, or distribute the original LZMA SDK code, either in source code form or as a compiled binary, for any purpose, commercial or non-commercial, and by any means.

Included in SDK

  • C++ source code for LZMA / LZMA2 encoder and decoder
  • C source code for LZMA / LZMA2 / XZ encoder and decoder
  • C# source code for LZMA encoder and decoder
  • Java source code for LZMA encoder and decoder
  • lzma.exe for .lzma compression and decompression
  • 7z library (C source code) for decoding .7z archives
