7z Format

A modern, open archive format providing exceptional compression ratios with strong encryption support.

What is 7z?

7z is a modern archive format with an open architecture, providing a high compression ratio. It was introduced as the native format for 7-Zip and has since become widely adopted for its flexibility and performance.

Key Features

🏗️
Open Architecture
Any new compression method can be added without changing the format specification.
🗜️
High Compression
LZMA and LZMA2 deliver industry-leading compression ratios.
🔐
AES-256 Encryption
Strong AES-256 encryption with SHA-256 key derivation to protect your files.
📁
Huge File Support
Supports files up to 16,000,000,000 GB in size.
🌐
Unicode File Names
Full Unicode support for international file names in any language.
⚡
Solid Compression
Solid archive mode compresses multiple files together for better ratios.

Compression Methods

7z has an open architecture, so it can support any new compression methods. Currently integrated methods:

MethodTypeNotes
LZMACompressionDefault method – best compression
LZMA2CompressionMulti-threaded improvement on LZMA
PPMDCompressionExcellent for text files
BCJFilterPre-filter for x86 executables
BCJ2FilterImproved BCJ filter
DeltaFilterFor binary data with regular patterns
AES-256EncryptionMilitary-grade encryption

LZMA – The Default Method

LZMA (Lempel–Ziv–Markov chain algorithm) is the default and primary compression method of the 7z format. Key characteristics:

  • High compression ratio with variable dictionary size (up to 4 GB)
  • Compression speed: approximately 2–8 MB/s on a 4 GHz CPU (2-thread version)
  • Decompression speed: approximately 30–100 MB/s on a 4 GHz CPU
  • Small memory requirements for decompression
  • Small decompression code size: approximately 5 KB

Encryption

7-Zip supports AES-256 encryption. The cipher key (256 bits) is derived from a user-defined text password using a SHA-256-based key derivation function. A large number of iterations makes brute-force attacks computationally expensive.

Applications Supporting 7z

Beyond 7-Zip itself, the 7z format is supported by WinRAR, PowerArchiver, TUGZip, IZArc, PeaZip, and many other archiving tools.
