Frequently Asked Questions

Is 7-Zip free for commercial use?

Yes, 7-Zip is open source software. Most of the source code is under the GNU LGPL license. You can use 7-Zip on any computer, including a computer in a commercial organization. You don't need to register or pay for 7-Zip.

Why can't 7-Zip open some ZIP archives?

In most cases, this means that the archive contains a header that does not conform to the ZIP specification. Try using the latest version of 7-Zip. If it still fails, the archive might be corrupted.
