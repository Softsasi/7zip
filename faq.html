Frequently Asked Questions

Answers to common questions about 7-Zip usage, compatibility, and development.

👤 User Questions

Yes, 7-Zip is free software. You can use it on any computer, including computers in commercial organizations. You don't need to register or pay for 7-Zip.

You must run 7-Zip File Manager in administrator mode. Right-click the 7-Zip File Manager icon, then click Run as administrator. You can then change file associations and other options.

Starting from version 15.06, 7-Zip uses a different file sorting order (by name) for solid 7z archives. The old default was sorting by extension/type.

You can restore the old behaviour by specifying qs in the Parameters field (or -mqs in the command line). Sorting "by type" may give better compression when the dictionary size is smaller than the total file size and similar files exist in different folders.

  • Increase dictionary size — helps when qs is not used.
  • Use qs mode if compression ratio is more important than file order.

In 99% of cases, the archive contains incorrect headers. Other ZIP programs may silently ignore these errors, but 7-Zip does not. The issue should be reported to the software that created the archive — it is not ZIP-compatible. Some ZIP archives also use unsupported methods such as WAVPack (WinZip).

Older versions (9.20 and below) supported only RAR 2/3/4 formats, not RAR5. Latest versions of 7-Zip support RAR5 archives. Update to the current release to open RAR5 files.

7-Zip doesn't know the folder path of the drop target — only Windows Explorer does. Explorer requires decompressed files on disk, so 7-Zip extracts to a temp folder first, then notifies Explorer of the paths. To avoid temp files, use the Extract command directly, or drag-and-drop from 7-Zip to 7-Zip.

You're likely using the *.* wildcard. 7-Zip's own wildcard parser treats *.* as "any file with an extension." To include all files (with or without extensions), use * instead of *.*, or omit the wildcard entirely.

In most cases you don't need -r. 7-Zip can compress subfolders without it.

7z.exe a c:\a.7z "C:\Program Files"

compresses "C:\Program Files" completely including all subfolders.

7z.exe a -r c:\a.7z "C:\Program Files"

searches for and compresses all folders named "Program Files" anywhere under C:\

32-bit Windows allocates only 2 GB of virtual address space per application, and this block can be fragmented by DLLs. 64-bit Windows has no such limitation, so you can use any dictionary size on Windows x64 as long as you have sufficient RAM.

EXE installer: Use the /S parameter for silent installation and /D="C:\Program Files\7-Zip" to specify the output directory. These switches are case-sensitive.

7z2601-x64.exe /S /D="C:\Program Files\7-Zip"

MSI installer:

msiexec /i 7z2601-x64.msi /q INSTALLDIR="C:\Program Files\7-Zip"

There are two common corruption scenarios:

  • You can see the file list but get Data Error or CRC Error when extracting.
  • 7-Zip reports "Cannot open file as archive."

Some data recovery may be possible. See the 7-Zip recovery guide for detailed procedures.

⚙️ Developer Questions

Visual C++ 6.0 or later is required. Some files also require a Platform SDK from Microsoft. In MSVC, place the SDK directories at the top of the "Include files" and "Library files" lists (Tools → Options → Directories). Note: the latest Platform SDK is not compatible with MSVC6 — use the Windows Server 2003 PSDK (February 2003) with MSVC6.

Yes, but you must document the following:

  • That you used parts of the 7-Zip program.
  • That 7-Zip is licensed under the GNU LGPL.
  • Provide a link to www.7-zip.org where the source code can be found.

Two approaches:

  • Use 7z.dll or 7za.dll — they work via COM interfaces. A small example is in the CPP\7zip\UI\Client7z folder of the source code.
  • Call the command-line version 7za.exe from your application.

7-Zip is licensed under GNU LGPL. In brief: any LGPL-licensed code must remain LGPL. You may create a wrapper DLL or modify the code, but the source of that DLL must be licensed under the LGPL or GPL. Other code in your application may use any license. If you need a more permissive license, consider the LZMA SDK, which is in the public domain.
